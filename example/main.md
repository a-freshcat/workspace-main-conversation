## 分工

| 角色 | 做什么 |
|---|---|
| **主对话** | 维护 `sum.md`；查看其它对话在做什么；审冲突与重复劳动； |
| **子对话** | 只干自己的部分；读 `sum.md` 了解全局；动共享文件前先留话；不改 `sum.md` |

使用者原则参考：**大 bug 另开新对话，小 bug 交给主对话。**

---

## 给进入本工作区的对话

1. 先读 [sum.md](sum.md) 的「对话清单」和「冲突审查」
2. 只建/只写**自己的**目录，并**立刻写 `.session-id`**
3. 要动 `~/.dsh` 运行时配置或插件本体前，先在 `sum.md` 留一行
4. 干完在自己的 README 写「我动了什么 / 没动什么」

> 你是**子对话**，不是主对话。不要把这里当自己的统筹区。
